# Web Development with ASP.NET 1.1

➡️ **Online course:**
[Web Development with ASP.NET 1.1](https://stahe.github.io/en-aspnet1.1-avril-2004/)

## Introduction

This document is an **educational resource** intended for students and does not claim to be an exhaustive course. Some topics require the guidance of a teacher, and several aspects of web development have been deliberately omitted. 

This resource forms part of a series of documents dedicated to **web development**, a subject the author has previously explored through two technologies:

* **Java**
* **PHP**

These documents share a **similar educational structure**, allowing the different technologies to be compared through analogous examples.

## Educational Approach

Unlike many books on ASP.NET, this resource does not immediately focus on the idea that an ASP.NET web application can be developed like a **Windows application**.

In traditional ASP.NET literature:

* the user interface is often built in IDEs such as **Visual Studio .NET** or **WebMatrix**
* **graphical controls** are placed within a visual interface
* these controls have **properties, methods and events**

In this document, these concepts are deliberately presented **later in the course**, as they are considered important but **not fundamental** to understanding web development.

## Main objective

The first part of the document focuses on the **fundamentals of web development**, regardless of the technology used (Java, PHP or ASP.NET).

Particular attention is paid to the architecture:

**MVC — Model / View / Controller**

This architecture is frequently recommended for designing structured and maintainable web applications.

However, the MVC approach is relatively incompatible with the ASP.NET philosophy of designing a web application as a Windows application. For this reason, the specific ASP.NET mechanisms aimed at increasing productivity are covered **in the second part of the course**.

## Tools used

This document focuses exclusively on **tools freely available on the Internet**, so that students can:

* download them easily;
* install the environment on their personal computers;
* reproduce and experiment with the examples presented;

An appendix entitled **‘Web tools’** explains how to obtain and install these tools.
